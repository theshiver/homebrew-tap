# theshiver/tap

```bash
brew install --cask theshiver/tap/apple-silicon-printer-drivers
```

Native Apple Silicon printer drivers for 3,800+ Canon, Epson, HP, Brother, Samsung and other printers. Fixes "The printer software is not compatible with this device" on macOS 27 and Tahoe. Project: https://github.com/theshiver/apple-silicon-printer-drivers
